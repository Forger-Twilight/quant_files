# Prompt 扩写指南（核心！）

用户提供的预设主题通常很简短（如"投资者情绪与股票收益"），但直接拿来做筛选和摘要的判定标准是不够的。你需要基于这句话**扩写**出具体的判定标准，让 LLM 能准确区分相关和无关内容。

## 扩写方法

拿到用户的一句话主题后，做以下三步扩写：

1. **拆解主题关键词** — 识别主题中涉及哪些核心概念。
   - 例：`投资者情绪与股票收益` → 核心概念是"投资者情绪"（换手率、封闭式基金折价、IPO 数量/首日收益、百度搜索指数、文本情绪等代理变量）、"股票收益"（截面收益、收益可预测性）、"关系"（实证检验）

2. **正面定义：什么算相关** — 将核心概念组合成一个清晰的判定标准句。
   - 例：`文献核心内容是构建或使用投资者情绪代理变量，实证检验投资者情绪与股票收益（或其可预测性）之间的关系`

3. **反面定义：什么算不相关** — 基于题录/文献的来源，列举常见的"沾边但不相关"类型。这一步很重要，因为一批文献中总有很多"提到了相关关键词但核心内容完全不是这个主题"的。
   - 例：`纯行为金融理论综述（无原创实证）、情绪对宏观经济/消费的影响、研究对象为债券/基金/期货等非股票资产、新闻报道与政策评论类文章`

扩写后的判定标准会同时用于 A4（题录初筛）和 B2（摘要 prompt 的角色设定）；仅综述模式（用户自带无题录 PDF）下，B1 fallback 也复用同一套标准。

## 默认市场范围约束(v1.1 起)

**默认检索范围限定 A 股市场**,在判定标准层实现,不动关键词层(关键词加市场限定会砍召回):

- **反面判定默认追加一条**:`研究对象为非 A 股市场(美股/港股/比特币等加密资产/期货/债券/外汇),除非主题本身明确指向该市场`
- 期货/债券作为对照或稳健性检验出现、主体仍是 A 股的,不因此判负
- 用户明确要求其他市场范围时,以用户指定为准,替换此默认

## 扩写示例

**用户输入**：`投资者情绪与股票收益`

扩写结果：
- 相关判定：文献核心内容是构建或使用投资者情绪代理变量（换手率、封闭式基金折价、IPO 数量/首日收益、百度搜索指数、文本情绪等），实证检验其与股票收益或收益可预测性的关系
- 不相关判定：纯行为金融理论综述（无原创实证）、仅讨论情绪对宏观经济/消费的影响、研究对象为债券/基金/期货等非股票资产、新闻报道与政策评论、投资者情绪的教学性介绍

**用户输入**：`ESG 评级与企业绩效`

扩写结果：
- 相关判定：文献核心内容是实证检验 ESG 评级或 ESG 表现与企业绩效（财务绩效 ROA/ROE、市场价值 TobinQ、股票收益等）之间的关系，含机制检验或异质性分析
- 不相关判定：ESG 信息披露政策评述（无实证）、ESG 评级方法与评级机构介绍、CSR 概念的纯理论辨析、教学案例研究、仅研究 ESG 与其他结果变量（如融资成本、绿色创新）而绩效不是核心内容
